#  LIBROLIBRE

**LibroLibre** es una biblioteca digital creada como ejercicio grupal por tres amigos apasionados por la lectura.  
El objetivo del proyecto es ofrecer una plataforma web sencilla y atractiva donde los usuarios puedan:

- Buscar libros por título, autor o género.  
- Consultar un catálogo organizado de libros electrónicos y audiolibros.  
- Ver detalles de cada libro (título, autor, sinopsis y género).  
- Registrarse para crear una cuenta y acceder al contenido disponible.  

---

## 🚀 Tecnologías utilizadas
- **HTML5** → estructura y secciones principales de la página.  
- **CSS3** → estilos y diseño responsivo para móviles y escritorio.  
- **JavaScript (Vanilla JS)** → interacción dinámica con el DOM y validaciones.  

---

## 🖥️ Funcionalidades principales

### Estructura
- Barra de navegación con enlaces a las secciones: **Catálogo, Registro y Sobre Nosotros**.  
- Formulario de búsqueda que permite filtrar libros por **título, autor o género**.  
- Sección de catálogo que muestra libros con su **título, autor y un breve resumen**.  
- Formulario de registro de usuarios para crear una cuenta.  

### Interactividad con JavaScript
- **Búsqueda dinámica:** los resultados aparecen sin recargar la página.  
- **Eventos:** uso de `onclick`, `onchange` y `submit` para capturar la interacción del usuario.  
- **Validaciones de formulario:** verificación de campos obligatorios antes de enviar el registro.  
- **Expresiones aritméticas:** conteo automático del número de libros que cumplen los criterios de búsqueda.  
- **Manipulación del DOM:** mostrar/ocultar resultados según la búsqueda del usuario.  

### Responsividad
- Diseño adaptable.  
- Distribución de elementos fluida utilizando CSS básico y media queries.
