# PICGALLERY

**PicGallery** es una galería de imágenes interactiva creada como ejercicio individual.  
El objetivo del proyecto es ofrecer una experiencia visual atractiva donde los usuarios puedan:

- Visualizar imágenes en miniatura organizadas en una cuadrícula.  
- Abrir cualquier imagen en tamaño grande en un **modal**.  
- Navegar entre las imágenes usando los botones **Siguiente** y **Anterior** dentro del modal.  
- Cerrar el modal haciendo clic fuera de la imagen o en el botón de cerrar.  

---

## 🚀 Tecnologías utilizadas
- **HTML5** → estructura y secciones principales de la página.  
- **CSS3** → estilos para la galería, modal y botones de navegación.  
- **jQuery** → interacción dinámica con el DOM, apertura del modal, navegación entre imágenes y efectos visuales (`fadeIn`, `fadeOut`).
